# Customer Analytics using SQL and Python

## Project Overview

An end-to-end customer analytics project using SQL and Python to extract, clean, analyze and model customer data.

## Objectives

- Extract and aggregate customer data using SQL
- Perform data cleaning and exploratory data analysis
- Calculate business KPIs
- Identify customer segments
- Build a decision-tree model for predictive analysis
- Perform forecasting
- Translate analytical findings into actionable business insights

## Tools & Technologies

- SQL
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Key Questions

1. Which customer segments contribute most to business performance?
2. What patterns and drivers can be identified from customer behaviour?
3. Which customer characteristics are associated with the target outcome?
4. Can customer behaviour be used to support predictive analysis?
5. What trends can be identified through forecasting?
